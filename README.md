# 文章收纳助手

一款面向家庭 NAS 自带的轻量 Android 客户端，用于收藏网页文章、离线阅读，并支持全本有声书点播。

## 功能特性

- 网页文章一键收藏（全文 + 图片快照本地保存）
- 离线阅读，无网络也可查看
- 访问密码保护（默认开启，登录后 30 天内免输）
- 有声书点播，支持小爱音箱语音播放
- 直连飞牛 NAS（WebDAV），无需第三方中转，不限速

## 安装

在下方 Releases 页面下载最新版 APK，安装到 Android 手机即可。

## 服务器地址配置

首次打开请在设置中把服务器地址指向你的飞牛 NAS：

    http://192.168.100.6:8090         局域网访问
    http://niyuqing.duckdns.org:8090  外网访问（需宽带支持 IPv6）

> 外网直连依赖 IPv6。电信宽带 IPv4 为运营商 CGNAT 大内网，无法从外网主动连入。

## 技术栈

- 客户端：Android WebView 封装
- 后端：飞牛 fnOS 自托管（Docker 容器）
- 数据：文章全文与图片快照本地化存储
